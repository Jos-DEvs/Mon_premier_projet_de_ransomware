# Mon Premier Projet de Ransomware

# Descrição
Este projeto tem como objetivo o desenvolvimento e a implementação, em Python, de um protótipo de ransomware destinado ao estudo dos mecanismos de criptografia e descriptografia de arquivos. O sistema foi projetado para operar sobre arquivos com as extensões `.txt`, `.xlsx`, `.docx` e `.png`, permitindo observar o processo de alteração dos dados durante a execução.

 Além da implementação das funcionalidades de criptografia e descriptografia, o projeto busca possibilitar o acompanhamento das diferentes etapas de execução do protótipo, desde o processamento dos arquivos até a aplicação e posterior reversão das transformações realizadas. Para fins de documentação e análise dos resultados obtidos, as etapas de execução e as alterações observadas nos arquivos são apresentadas por meio das capturas de tela disponibilizadas a seguir.
